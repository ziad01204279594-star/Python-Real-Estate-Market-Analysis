 🏙️ New York Real Estate Market Analysis

 📌 Project Overview
This project provides a comprehensive Exploratory Data Analysis (EDA) of the New York housing market. The objective is to analyze property price distributions, examine structural factors affecting home values (such as bedroom and bathroom counts), and identify major property categories across the dataset.


## 📊 Key Findings & Insights
* **Price Distribution:** Most homes in the filtered dataset are concentrated in a lower price range, with fewer very expensive properties.
* **Bedrooms & Bathrooms vs. Price:** Homes with more bedrooms and bathrooms often have higher prices, although there are still many outliers.
* **Property Size Impact:** Property size appears to have a positive relationship with price.
* **Market Composition:** Some property types appear much more often than others in the dataset.

🛠️ Tools
 *Pandas:** Data loading and manipulation
 *NumPy:** Numerical processing
*Matplotlib:** Data visualization
